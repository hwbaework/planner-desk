# Planner Desk · 기획 데스크

IT 기획자 / PMO용 프로젝트 관리 화면. **HTML 파일 하나**로 동작하고, DB 없이 데이터를 HTML 안에 넣어 저장한다. 디자인은 Jira(색 #0C66E4, 유형 아이콘, 보드·타임라인 구조)를 참고했다.

## 쓰는 법

1. `index.html`을 Chrome/Edge로 연다 (더블클릭).
2. 입력한 내용은 브라우저에 자동 저장된다.
3. **저장 (Ctrl+S)** → 현재 데이터가 들어간 HTML 파일로 저장된다.
   - 저장 위치를 한 번 정하면 그 뒤로는 같은 파일에 자동 저장된다.
   - 저장한 HTML을 다른 PC에서 열어도 데이터가 그대로 보인다.
4. **설정**(톱니바퀴): 불러오기 · 다른 이름으로 저장 · JSON 내보내기 · 글자 크기 · 화이트/다크 · 경고 기준일.
5. **검색 (Ctrl+K)**: 업무 · 개발 전달 · 데이터 · 산출물 · 요구사항 · 화면 · 테스트 · 일정 · 메모를 한 번에 찾는다.

## 경고 (설정에서 기준일 변경)

| 경고 | 조건 |
|---|---|
| 접수 노티 없음 | 전달 후 영업일 2일 넘게 회신 없음 (프로젝트별 변경 가능) |
| 완료 노티 없음 | 완료 예정일이 지났는데 완료 노티 없음 |
| 진행 공유 없음 | 마지막 응답 뒤 영업일 5일 넘게 소식 없음 |
| 내 검수 대기 | 완료 노티 후 2일 넘게 기획 검수 안 함 |
| 승인 회신 없음 | 산출물 검토요청 후 영업일 3일 넘게 승인 없음 |
| 데이터 미수신 · 데이터 협의 지연 | 합의한 수신일이 지났는데 수신 기록 없음 · 협의가 5일 넘게 멈춤 |
| 결함 미전달 · 재테스트 필요 | Fail인데 개발에 안 넘김 · 결함 처리됐는데 다시 테스트 안 함 |
| 화면 변경 후 미전달 | 개발에 넘긴 화면을 개정했는데 변경분을 안 넘김 |
| 화면 미반영 요구사항 | 확정된 기능 요구사항에 연결된 화면 없음 |
| 업무 마감 지남 · 정기 업무 지남 · WBS 지연 · 산출물 일정 지연 | 날짜가 지났는데 끝나지 않음 |

## 메일 연동 (하이웍스 · Gmail · 네이버 · 기타 POP3/IMAP, 읽기 전용)

메일을 지우거나 읽음 처리하지 않는다. 비밀번호는 화면과 설정 파일에 저장하지 않고 실행할 때만 입력한다.

1. 메일 환경설정에서 POP3(하이웍스) 또는 IMAP 사용을 켠다. 관리자가 막았다면 IT팀에 문의.
2. Planner Desk → 메일 수신 → **메일 연동 설정**에서 메일 서비스와 계정을 입력하고, **설정 파일 저장**으로 `tools` 폴더에 `mail_config.json`으로 저장한다.
3. 연결 확인:

```bash
tools\sync_mail.bat --test
```

4. `tools\sync_mail.bat` 실행 → 저장소 루트에 `mail_inbox.json` 생성 → 화면에서 **동기화 파일 불러오기**.

30분마다 자동 실행:

```bash
schtasks /Create /SC MINUTE /MO 30 /TN "PlannerDesk 메일 동기화" /TR "\"C:\Users\RMS\Desktop\java\planner-desk\tools\sync_mail.bat\" --quiet"
```

## 자동 점검

로컬 서버를 띄우고 `http://localhost:5178/tests/selftest.html`을 연다. 화면 · 보드 · 경고 · 메일 매칭 · 저장/불러오기 왕복 · 회의록 인식 · 메모 변환 · 단축키 등 72개 항목을 확인한다. 점검은 분리된 저장 공간(`?selftest`)에서 돌아서 실제 데이터를 건드리지 않는다.

```bash
npx --yes http-server@14.1.1 -p 5178 -c-1
```

## 커밋 전 검사

`node tools/check.js`가 `index.html`과 `tests/selftest.html`의 스크립트 문법 오류와 이모지를 확인한다. 저장소를 받은 뒤 한 번 아래를 실행하면 커밋할 때마다 자동으로 돈다.

```bash
git config core.hooksPath .githooks
```

## 커밋하지 않는 것

데이터가 든 저장본(`planner-desk_*.html`), 메일 설정과 수신 파일(`mail_config.json`, `.mail_state.json`, `mail_inbox.json`), CSV·주간보고 내보내기는 `.gitignore`로 제외한다.

데이터 구조는 `index.html` 안의 `emptyState()` 참고. 저장 파일은 `var EMBEDDED_DATA = {...}` 한 줄만 바뀐다.
