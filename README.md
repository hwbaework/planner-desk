# Planner Desk · 기획 데스크

IT 기획자 / PMO용 프로젝트 관리 화면. **HTML 파일 하나**로 동작하고, DB 없이 데이터를 HTML 안에 넣어 저장한다.

## 쓰는 법

1. `index.html`을 Chrome/Edge로 연다 (더블클릭).
2. 입력한 내용은 브라우저에 자동 저장된다.
3. **저장 (Ctrl+S)** → 현재 데이터가 들어간 HTML 파일로 저장된다.
   - Chrome/Edge: 저장 위치를 한 번 정하면 그 뒤로는 같은 파일에 자동 저장된다.
   - 저장한 HTML을 다른 PC에서 열어도 데이터가 그대로 보인다.
4. **설정**(톱니바퀴)에서 불러오기 · 다른 이름으로 저장 · 글자 크기 · 화이트/다크를 바꾼다.
   - 불러오기: Planner Desk 백업 HTML/JSON, 또는 예전 `사업관리 대시보드` 백업 HTML(업무 · 일정 · 정기 업무 · 메모).

| 메모·회의록 | 프로젝트별 메모, 자동 저장 |

## 경고 규칙 (설정에서 변경)

- **접수 노티 없음**: 전달 후 영업일 2일 넘게 회신 없음 (프로젝트별로 바꿀 수 있음)
- **완료 노티 없음**: 완료 예정일이 지났는데 완료 노티 없음
- **진행 공유 없음**: 마지막 응답 뒤 영업일 5일 넘게 소식 없음
- **승인 회신 없음**: 산출물 검토요청 후 영업일 3일 넘게 승인 없음
- **내 검수 대기**: 완료 노티를 받았는데 2일 넘게 기획 검수를 안 함
- **데이터 미수신**: 합의한 데이터의 수신 예정일이 지났는데 수신 기록 없음
- **업무 마감 지남 / 정기 업무 지남**

## 메일 연동 (하이웍스 · Gmail · 네이버 · 기타 POP3/IMAP, 읽기 전용)

메일을 지우거나 읽음 처리하지 않는다. 비밀번호는 화면과 설정 파일에 저장하지 않고 실행할 때만 입력한다.

1. 메일 환경설정에서 POP3(하이웍스) 또는 IMAP 사용을 켠다. 관리자가 막았다면 IT팀에 문의.
2. Planner Desk → 메일 수신 → **메일 연동 설정**에서 메일 서비스와 계정을 입력하고, **설정 파일 저장**으로 `tools` 폴더에 `mail_config.json`으로 저장한다.
3. 연결 확인:

```bash
tools\sync_mail.bat --test
```

4. `tools\sync_mail.bat` 실행 → 저장소 루트에 `mail_inbox.json` 생성 → 화면에서 **동기화 파일 불러오기**.

회사를 옮기면 메일 연동 설정에서 서비스 · 서버만 바꾸면 된다.

30분마다 자동 실행:

```bash
schtasks /Create /SC MINUTE /MO 30 /TN "PlannerDesk 메일 동기화" /TR "\"C:\Users\RMS\Desktop\java\planner-desk\tools\sync_mail.bat\" --quiet"
```

`mail_config.json`, `.mail_state.json`, `mail_inbox.json`, 데이터가 든 저장본(`planner-desk_*.html`)은 `.gitignore`로 커밋하지 않는다.

## 개발

```bash
npx --yes http-server@14.1.1 -p 5178 -c-1
```

데이터 구조는 `index.html` 안의 `emptyState()` 참고. 저장 파일은 `var EMBEDDED_DATA = {...}` 한 줄만 바뀐다.
